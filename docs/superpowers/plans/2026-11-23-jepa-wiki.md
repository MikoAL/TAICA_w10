# JEPA LLM Wiki + 教學簡報 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一個以 6 篇原文為基礎的 JEPA LLM Wiki、一份只引用 Wiki 的 reveal.js 教學簡報，以及能證明 Wiki↔簡報↔原文對應的檢查紀錄。

**Architecture:** Claude Code 執行每個節點；`CLAUDE.md` 是 Wiki 規則；`scripts/` 下的 Python 檢查程式做確定性檢查；一個只拿到簡報文字與被引用 Wiki 頁的 subagent 做語意檢查。每輪檢查輸出存在 `logs/run-N/`。

**Tech Stack:** Python 3 標準庫 + pytest；reveal.js（CDN，版本由 Haiku 查官方文件決定）；playwright-core（npx）搭配系統 Chrome 做瀏覽檢查；GitHub Pages。

**Spec:** `docs/superpowers/specs/2026-11-23-jepa-wiki-design.md`

## Global Constraints
- 期限 2026-11-23 23:59。
- `raw/` 不進 git；repo 只有 `raw/SOURCES.md`（id、標題、URL、下載日 2026-11-23）。
- Source ids：`meta-lecun-blog`, `meta-ijepa-blog`, `ijepa`, `vjepa`, `vicreg`, `jepa-anything`。原文檔：`raw/<id>/paper.txt`（jepa-anything 用 `paper_html.txt`）或 `raw/<id>/page.txt`。
- Wiki 與簡報：繁體中文，英文術語第一次出現附中文。
- 簡報寫作者只讀 `wiki/`。
- JEPA-Anything 的結果寫成「論文報告…」。
- 反思只寫實際檢查結果顯示的東西。

## Wiki page format（`CLAUDE.md` 定義，檢查程式依此實作）
```markdown
---
title: JEPA
type: concept        # concept | source
sources: [ijepa, meta-ijepa-blog]
---
# JEPA（Joint-Embedding Predictive Architecture）
內文句子。[^ijepa-1]

## 引文
[^ijepa-1]: [ijepa](../sources/ijepa.md) — "exact quote from raw text"
```
- 內文每個段落／條列項至少一個 `[^…]`。
- 每個 footnote 定義形如 `[^<id>-<n>]: [<id>](…) — "<quote>"`，`<id>` 必須是 source id。
- 頁面連結一律相對路徑 `.md`。

## Review Focus
1. 引文含彎引號／連字號斷行：正規化後仍要比對得到（測試 `test_quote_normalization`）。
2. 內文數字（例如 72 小時、12 張）不在任何被引用的引文中 → 要報錯（`test_number_not_in_quote`）。
3. 簡報引用的 Wiki 錨點不存在 → 要報錯（`test_slide_missing_anchor`）。
4. 簡報數字不在被引用 Wiki 頁 → 要報錯（`test_slide_number_unsupported`）。
5. 投影片內容超出畫面（1280×720）→ 瀏覽檢查要報錯。

### Task 2: `scripts/check_wiki.py`（TDD）
**Interfaces — Produces:** `python3 scripts/check_wiki.py [--raw raw] [--wiki wiki]` → 印出每個問題一行 `CODE path:line message`，最後一行 `SUMMARY errors=N warnings=M`；有 error 時 exit 1。函式 `normalize(s: str) -> str`、`find_quote(quote: str, text: str) -> bool`。
- 錯誤碼：`QUOTE_NOT_FOUND`、`UNKNOWN_SOURCE`、`UNCITED_PARAGRAPH`、`BROKEN_LINK`、`NUMBER_NOT_IN_QUOTE`、`MISSING_FRONTMATTER`、`ORPHAN_PAGE`（index.md 沒列到，warning）。
- `normalize`：NFKC、彎引號→直引號、行尾連字號斷行接回、所有空白壓成一個空格、小寫。
- [ ] 寫 `tests/test_check_wiki.py`（fixtures 用 tmp_path）：`test_quote_found`、`test_quote_normalization`、`test_quote_not_found`、`test_unknown_source`、`test_uncited_paragraph`、`test_broken_link`、`test_number_not_in_quote`（段落寫「72 小時」但引文沒有 72 → error）。
- [ ] 跑測試確認失敗 → 實作（交給 Haiku）→ 跑測試通過 → commit。
